# V9.0交付前的反事实演练

在内部做以下五轮，不把答案逐镜重复输出给用户；失败时先改镜头再交付。

1. **删镜试验**：删去每个重点镜头，是否会丢失一种信息、一个可见行动、关系变化、关键接触或必要余波？若没有，镜头应合并或承担新的职责。普通承接镜头可简单，但仍需把状态向前推进。
2. **换技法试验**：把复杂运动换成稳定机位后，观看结果是否一样？若一样，选更清楚的稳定拍法。把特写换成双人中景后，关键表演是否丢失？若不丢，优先保关系。技术选择必须有可解释的损益。
3. **演员连演试验**：把相邻镜头只读“人物动作与持物”，演员能否不中断地做完？把相邻镜头只读“镜头位置与轴线”，摄影是否始终知道谁在左、谁在右、从何处接上？若不能，补回收、补步或空间镜，而非靠“快速剪辑”遮盖。
4. **信息与音画试验**：人物获知事实前是否出现知情表演？声音是否提前泄露未允许的真相？光源、技能余光、尘雾和伤势是否跨镜一致？音效是否与实际触发或接触同源？
5. **方案差异试验**：随机挑本集三个关键镜头，假设换用另一导演方案，视角、信息释放、演员策略、景别或摄影节奏应至少有两项真正不同；否则方案只有名称，没有执行。

可用三个不同性质的短场面做模板回归：一场双人关系变化，检查同框、听者反应和空间权力；一场有连续攻防的动作，检查步法、攻防线、受力、恢复与跨镜接力；一场有既定能力的特效，检查技能边界、范围、材质、碰撞和消散。范例只能测试方法，绝不成为用户剧本。若目标模型不能读全模板或原稿，先说明已读取范围，要求分段提供；不能只凭一部分资料声称完成全剧核对。
