# V10.0交付前的反事实演练

在内部做以下七轮，不把答案逐镜重复输出给用户；失败时先改镜头再交付。

1. **原稿覆盖试验**：把各镜实际发生的事件、对白、反应按顺序写成一句话，对照拍点账本。必须拍点有无落点？同一句台词或攻击是否重复？导演细化是否越过原稿能力和结果？失败先补因果，不按镜数凑足。
2. **删镜试验**：删去每个重点镜头，是否会丢失一种信息、一个可见行动、关系变化、关键接触或必要余波？若没有，镜头应合并或承担新的职责。普通承接镜头可简单，但仍需把状态向前推进；合并后重做原稿覆盖试验。
3. **换技法试验**：把复杂运动换成稳定机位后，观看结果是否一样？若一样，选更清楚的稳定拍法。把特写换成双人中景后，关键表演是否丢失？若不丢，优先保关系。技术选择必须有可解释的损益。
4. **三遍接力试验**：只读演员动作与持物，能否连演；只读机位与左右方向，能否画空间图；只读声音、光线与特效，能否追踪同一来源和消散。若不能，补回收、补步、空间镜或改变切点，跨Part同样检查。
5. **信息与音画试验**：人物获知事实前是否出现知情表演？声音是否提前泄露未允许的真相？光源、技能余光、尘雾和伤势是否跨镜一致？音效是否与实际触发或接触同源？
6. **节奏与容量试验**：从开头到结尾能否感到逼近、判断、爆发和余波的强弱变化，而非机械均速？自然对白、动作、听者反应能否在Part上限内完成？若不能，合并重复职责或拆Part，不加速演员也不删剧情。
7. **方案差异试验**：随机挑本集三个关键镜头，假设换用另一导演方案，视角、信息释放、演员策略、景别或摄影节奏应至少有两项真正不同；否则方案只有名称，没有执行。

可用四种不同性质的短场面做模板回归：双人关系变化，检查听者反应和空间权力；连续攻防，检查步法、受力与跨镜接力；既定能力特效，检查范围、材质、碰撞与消散；打斗与特效混合，检查摄影运动不会遮掉身体和胜负。最好另选一段真实剧本做私有回归，逐条标注通过/失败与需要修订的模板规则；原稿不能因此进入通用模板或公开包。结构检查通过不等于镜头质量已获真实模型验证。若目标模型不能读全模板或原稿，先说明已读取范围，要求分段提供；不能只凭一部分资料声称完成全剧核对。
