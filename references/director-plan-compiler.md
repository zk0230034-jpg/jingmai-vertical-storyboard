# 导演方案如何真正影响逐镜

方案是全片的选择规则，不是名称。剧本诊断先逐场记录：原稿依据 → 观众应感到或理解什么 → 可能拍弱的原因 → 两三种可用设计杠杆，并标记必须落实、可选加强、不适用。至少检查人物关系、信息差、动作因果、特效功能、空间可用性、听者反应与结尾动力。

不同方案应在观众跟随视角、信息释放顺序、镜头距离、调度、声音或节奏上有真实分歧。提出推荐及取舍；用户可选、融合或自定义。选定后先形成“导演执行卡”，再规划Part：

| 项目 | 必须写出的决定 |
| --- | --- |
| 观看任务 | 本集钩子、转轴、高潮、结尾分别要让观众知道与期待什么 |
| 跟随与知情 | 主要跟随谁；观众比人物早、同刻还是晚知道关键事实；何时允许看到真身或证据 |
| 表演 | 核心人物的目标、策略、克制或外放程度；哪句台词改变关系 |
| 动作体系 | 各方能力、身体结构、移动方式、距离优势与禁用动作；胜负结果不可变 |
| 特效语法 | 各能力的来源、作用范围、核心材质、外围结构、运动、接触与消散；视觉层级不能互相打架 |
| 摄影 | 景别分配、关系镜头、主要运动、关键接触的停稳、特殊视角的触发条件 |
| 声音与光 | 已有声源和光源；何处减声或突出动作声；新增变化要有剧情来源 |
| 视觉组织 | 哪个原稿已有的空间关系、动作或形象可成为本集/本场的视觉线索；何处保持、何处因剧情转折而改变；没有可靠材料时不硬造母题 |
| 节奏 | 哪些过程快、哪些判断和受力必须停；每场的加速、停留、释放如何组成整集曲线；Part容量与镜数的安排 |
| 禁止漂移 | 该方案不能使用的提前揭示、无因果慢动作、空泛英雄镜头、额外伤势或能力 |

把执行卡映射为“重点 → 原稿拍点 → Part → 镜头职责 → 相邻切口”。每个重点至少在镜头里有触发、过程、对手反应、结果，不能只在摘要写“重点刻画”。导演方案还应规定**何时不展示**：如贴近受压者的有限视角，不可先用全知镜头交代背后的威胁；空间关系方案则可能需要先稳定同框。方案差异应落在观众知情顺序、演员调度、声源安排和镜头距离，而不只是滤镜颜色。在交付前反查至少三处关键镜头：若换另一个方案，景别、视角、信息顺序和表演仍完全相同，说明方案没有落地，应重设计。
