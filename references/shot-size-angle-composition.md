# 景别、视角与构图：决定观众站在哪里、能看见多少

## 景别按“必须读清的行动”选

| 景别/关系形态 | 优先承担的职责 | 需要保留或防止丢失 |
| --- | --- | --- |
| 大全景/远景 | 建立场域、追逐路线、包围或规模差，或在冲击后重看结果 | 人物在9:16中可能太小；不要求观众读面部微表情 |
| 全景/全身双人镜 | 看清落脚、身体距离、进攻方向、谁挡路和谁退让 | 不是只有“交代环境”的功能；可让地位变化在同镜发生 |
| 中全景/膝上景 | 同时读身体姿态、持物、进退与适度表演 | 复杂步法仍需保留支撑脚，不能截掉命中原因 |
| 中景/双人中景 | 看清两人对话、手部动作、距离变化和接受/拒绝 | 若只能看到一个人的脸，关系可能被剪没了 |
| 中近景 | 看脸、肩线、手部细节及对手在场感 | 人物可以停顿、忍住或选择；不能替代必要的全身受力 |
| 近景/特写 | 读细微表演、关键信息、受伤或道具状态；让某个瞬间更有重量 | 每次特写必须有证据或变化，连续同信息特写合并 |
| 大特写/局部插镜 | 极关键的触发、接触或证据细节，短暂控制观众注意力 | 必须能从前一镜定位部位，随后回到人物/空间后果；不可碎片化掩盖打斗 |

景别变化不是从远到近的自动阶梯。关系可从近景退到双人全景，让观众第一次看见两人实际隔得多远；动作可先中景读拳线，再全景看受力；揭露可以先给听者近景，证据稍后才露出。景别的先后顺序必须服从信息时序和导演方案。

## 视角是知情位置，不是情绪按钮

| 候选视角 | 观众获得的关系或认知 | 使用条件与防误用 |
| --- | --- | --- |
| 平视观察/中性关系机位 | 让身体和事实自己说话，适合争执、表演与动作基准镜 | “平视”不等于平庸；若演员走位有戏，不必强行俯仰 |
| 角色主观（POV） | 与该角色同一刻发现、误判或遗漏信息，代入其受限认知 | 只显示此刻实际可见的东西；要有前后视线与身体位置作锚 |
| 近似主观/贴身受限视角 | 保留角色轮廓或肩背，让观众受其处境限制，又不完全成为眼睛 | 恐惧、追逐、幻觉可用；关键身体接触仍须有客观补镜 |
| 过肩/肩后 | 让前景人物的存在持续见证、遮挡、压迫或亲近对方 | 写清哪一侧肩线、对手距离与目光；不机械拍全套正反打 |
| 侧面双人/轴线同侧 | 交代双方进退、攻击线和相对距离 | 打斗或挡路时尤其有用；转到反侧前需重建方向 |
| 正面迎视/直视镜头 | 可使观众承受人物的凝视、逼迫或主观交流 | 须符合叙事视点，不能让普通对话无故“看镜头” |
| 背面/背影跟随 | 暂不交代脸，先交代目标、迟疑、逃离或环境压力 | 不能要求观众从背影读精细面部变化；出场揭脸应有信息价值 |
| 低机位/贴地仰视 | 放大接近中的体量、脚步或支配感，也可从受压者位置看威胁 | 高低差、距离变化或实际体量要有依据；低机位不自动等于英雄 |
| 高机位/俯视/顶视 | 显示路线、包围、孤立、阵形或谁控制出口 | 顶视能解释空间但可能削弱表情与接触；不能只为画面图案 |
| 斜轴/局部遮挡视角 | 以既有墙、门、人影限制信息，再在行动中释放 | 不擅自把普通对话变成偷窥或惊悚；遮挡必须改变认知 |
| 荷兰角/轴线偏斜 | 表现已发生的心理或世界失衡，再与正轴形成对照 | 写触发、倾斜方向与归正；单独斜一下不等于“高级” |

同一角度不会稳定地产生同一种情绪。低机位也可能拍出角色虚张声势，高机位也可能让观众看清其逃跑路线。视角的真实意义来自“谁在看、知道多少、身体处于哪里”，以及它与前后镜头的对照。

## 构图把关系拍成空间事实

可选择居中对称、偏置与负空间、三分位置、纵深前后景、双人分列、画中框、已有物体遮挡、轮廓/剪影、空间重心转移、人物出入画。每次只问：观众是否因此更清楚地看到孤立、阻挡、亲近、误判、权力或危险？例如“门口的人占据画面较近一侧，室内的人绕过桌边后两人第一次同深度同框”；这是可执行的构图变化。只写“三分构图、电影感、人物占四分之三”而不说谁被排除、行动怎样改变画面，并不构成设计。

构图必须容纳演员真实的行动终点：人物向右离开，留足右侧的行动空间；攻击从画左进入，接触点不能被裁在边缘；两人关系需清楚时让肩、手、脚或持物保持必要可见。竖屏下可以用前后景或上下方位创造层级，但不能凭空把横向距离改成纵向距离，也不能为填满画幅压缩原有场景规模。

## 焦段与透视只在影响空间感时说明

相机贴近人物、用较广视野保留其身后环境，可让观众同时感到人物与迫近的空间；但脸和身体边缘若被夸张拉伸，需退开或换更自然的视角。较窄视野可隔离远处证据、让前后人物看似更贴近，但会损失路线和纵深，不适合首次交代复杂攻防。自然透视最适合让表演和动作自行成立。提示词优先描述**机位距离、画面内可见空间和透视结果**，不必堆镜头毫米数；不把“长焦”当作自动的电影质感，也不把“广角”当作自动的沉浸感。
