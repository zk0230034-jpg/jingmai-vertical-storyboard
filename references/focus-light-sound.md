# 焦点、景深、光影和声音：控制何时看见、听见、相信

## 焦点与景深是信息调度

- **深焦/较大清晰范围**：两个人或人物与环境证据需要同时被理解时，让关系共存；例如一人在近处行动，另一人在后处决定是否响应。场景没有纵深时不硬造深焦戏。
- **浅景深**：在空间已经交代清楚后，使细微表演、关键证据或暂时孤立的感受被突出；关键追逐路线、多人攻防和接触点不能因背景全糊而失去因果。
- **移焦/焦点交接**：前景必须先有值得看的行动，某个可见或可闻触发让观众改看后景，最后在新信息处停留并看见人物回应；如果只是“镜头很高级地从A焦到B”，删掉。
- **前景遮挡+相对运动**：先写被挡住的事实是什么，谁的行动或摄影机移动使它露出；遮挡物来自既有场景。它可以延迟危险或让关系被空间规则分隔，但不能无故增加门、窗、烟雾或偷窥意味。

焦点、遮挡和运镜不必三件一起上。先选承担信息交接的主要方式；若已有演员转身和摇摄能完成揭示，就不需要再叠一次移焦。浅景深、散景、镜头光斑不等于高级感，它们会让观众少看见东西，必须有合理的“少看见”理由。

## 光影按来源、方向、质地、关系变化来设计

先确认场景已有日光、灯、火、窗、屏幕或剧本允许的技能发光；同场记录光源位置、时间、色温、硬软、阴影方向和反差，跨镜不跳。没有可信来源，不凭“电影感”添逆光、边缘光、顶光、体积光、霓虹或频闪。

| 可选光影关系 | 适用的观看任务 | 必须可见的执行边界 |
| --- | --- | --- |
| 侧光与明暗分区 | 人物在试探、隐藏与坦露之间变化 | 现有侧向光从何处来；人物走过哪条光区边界，表情何时被看清 |
| 柔和近源光 | 保留皮肤与眼神细节，强调可接近或脆弱 | 光源在场景何处；不把所有文戏都统一打成“温暖治愈” |
| 硬光/清晰投影 | 暴露压迫、警觉、障碍或人物与空间的冲突 | 阴影落在哪里，人物或物件如何穿过；阴影不能每切一镜就反向 |
| 背光/剪影 | 暂不看清身份，或用体形与行动先介绍人物 | 背后确有光源；脸何时允许显露，不能遮掉必要表演 |
| 现有光区穿越 | 用人物行动改变其被看见的程度，呈现靠近出口或进入危险 | 光不自己变；人物从哪里走到哪里，衣料/肤色怎样连续响应 |
| 技能局部照明 | 特效能力真的发光时，让手、脸、衣物和邻近表面受照 | 光随技能形成、移动和消散；范围不超越能力与既有环境 |
| 低反差/高反差变化 | 调整整体可辨层次与威胁感，可在场次或真实光源改变时变换 | 不靠单镜随意改调色制造“反转”；先保证眼神、接触与目标可读 |

光影可塑造气氛，但先问它是否帮助观众看到人物选择、信息隐藏或空间边界。重点镜头才详细描写；普通承接镜头继承场景光，不在每镜复制一段调光说明。颜色也不是情绪的固定密码：“冷色=悲伤、暖色=幸福”不能替代场景因果。

## 环境音效参与叙事，不只填满“环境音效”字段

先区分角色能听见的现实声、仅供观众听见的主观声、原稿明确的音乐；未经原稿授权不添加背景音乐。声音可承担四种任务：**定位**（远近、左右和混响建立空间）、**预警**（危险先有可听线索，随后角色寻找）、**触感**（衣料、脚步、格挡、接触、受力分层）、**情绪对照**（环境持续而人物停顿，或声场因有依据的主观失衡而收窄）。每次说明声源、距离、遮挡/混响、何时进入与退去、人物是否听见。

对白永远要听清；打斗冲击声对应可见接触而非独立爆音。声音先行、声音延续、突然静默均是可选切点，不是每段配额。声音跨镜要沿同一空间逻辑变化，例如脚步由后方逼近而非切镜后凭空出现在前方。真正有效的“静”是先建立的声场在人物主观感受中改变，不能无缘无故把所有环境声抽空。
