# 武术词汇使用边界与动作翻译

术语分三层。第一层是通用身体动作，可直接按角色能力采用：提膝护中线、前臂架挡、侧闪、沉肩、转髋、垫步、撤步、摆步、扣步、贴身靠击、截击、借力转身。第二层是训练背景明确时采用的拳种技法描述。第三层是门派、流派、命名套路与专有招式，只在剧本写明或用户授权时命名。不能因角色“会打”就称其使用八卦掌、太极拳或咏春。

| 术语 | 必须翻译成可拍动作 | 常见误用 |
| --- | --- | --- |
| 提膝 | 哪条腿提起，膝盖是护腹、截腿还是撞击；支撑脚怎样承重；落脚后往哪里 | 把提膝写成无目标的帅气姿态 |
| 格挡/架挡 | 哪只手或前臂从何侧挡哪条攻击线，接触后拳爪偏向哪里，身体是否仍中招 | “挡住全部攻击”却不说明接触与后手 |
| 侧闪/避线 | 头肩和落脚同时离开哪条攻击线，攻击从何处擦过，对手惯性暴露什么 | 只写上身晃动却脚和重心没动 |
| 摆步/扣步 | 哪只脚外摆或内扣，身体绕对手哪一侧换位；落脚后视线和出手方向如何变化 | 用脚法名代替方位交代 |
| 走圈换位 | 围绕对手的哪个方向走、占住哪个侧后角，过程中如何保持防守 | 凭空说“八卦游龙步”制造不存在的流派 |
| 沉肩转髋送掌 | 掌根或掌缘击向何处，后脚怎样蹬地，髋部怎样带动而非只挥手 | 肩膀不动、脚步悬空却打出巨大冲击 |
| 贴身靠击 | 先如何进入近距，肩背何处接触，受力者怎样补退与恢复 | 未建立距离就突然肩撞 |
| 虚实/佯攻改线 | 第一击诱使对方封住哪里，第二击如何从其回防空隙进入 | 连续两击互不因果 |
| 截击/封中线 | 迎向对手启动的哪条攻击线，用手、脚或兵器抢先截到何处，自己哪侧仍受保护 | “截住对方全部攻势”却不说明实际碰撞 |
| 卸力/带偏 | 接触点沿原攻击方向怎样转移，对手重心被带到哪只脚，自己如何保持支撑 | 用“以柔克刚”四字替代身体路径 |
| 提膝后落步 | 膝是护中、撞击还是避开下路，落脚如何变成贴近或撤离的下一步 | 膝盖悬在空中却立刻发动需要双脚支撑的重击 |
| 转身反击/贴身短打 | 转身由哪次被带偏的力量引发，肘、掌或肩从哪一侧进入可及距离 | 为潇洒而无因果旋转，甚至把背部暴露给原有攻击 |
| 扫腿/破重心 | 先让对方哪条腿承重，哪只脚从何方向扫哪处，受力者如何补步或倒地 | 上半身被打中却脚下无因地飞起；未训练角色精密扫摔 |

中国武术的画面特点可以从圆转步法、抢中线、借势换位、贴身短打等动作规律借鉴；只有剧本确认角色学过相应门派，才写“八卦掌的摆扣步”等明确归属。不同兵器的重心、攻击线和护手方式分别设计，不把击剑词汇硬套在刀枪、徒手或妖兽上。妖兽可扑、拍、咬、甩尾、伏低、蹬地，但不能拟人化提膝格挡。

示例句式：他左脚向外摆开拳线，右前臂从内侧架住对方直拳，拳头从耳旁擦过；对方前冲未停，他以后脚为轴扣步绕到侧面，掌根贴近胸口推出。接触后对方上身先偏、后脚补退，双方重新拉开距离。此句只是动作结构示例，不允许直接复制到与角色训练、身体或原稿结果不符的剧本。
