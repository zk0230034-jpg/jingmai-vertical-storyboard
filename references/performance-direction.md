# 文戏与情绪的可见表演

每个重点文戏先给演员一个可执行任务：此刻想从对方得到什么，隐藏什么，用何种策略，哪句台词或哪个动作迫使策略改变。把情绪写成“触发前状态 → 接收刺激 → 可见泄露 → 掩饰或应对 → 对手反应 → 余波”，可在一个镜头内完成多个阶段，不机械切六镜。

选择少量最有效的身体信号：视线停住、呼吸被截断、下颌收紧、手指松开或抓紧、肩颈改变、重心移向门口、话到嘴边又吞回。每一个都要对应刺激和结果；不能每镜堆满微表情。全景看姿态、距离和走位，近景才承担细小眼神或唇角变化。

倾听者必须接收信息。关键台词可留在画外，让听者的目光、姿态、选择或距离变化成为镜头主事。说话人下一句不能抢走听者的反应。两人关系变化优先由真实走位、挡路、退让、同框或过肩呈现；镜头推进、浅景深和光影只能放大已经发生的变化。

揭露戏先决定观众与人物各在何时知道事实，再决定先拍证据、说话者还是听者。角色获知前不能提前演出知情反应。克制的情绪可以比哭喊更强，重点是看见人物试图保持控制而控制失效的具体时刻。

自检：删掉“伤心、愤怒、深情、震惊”后，演员是否仍知道要做什么？对手是否有可见反应？镜头结束时两人的关系是否与开头不同？如无变化，补行动或合并镜头。
