# 打斗、追逐与动作流

先锁事实：双方目标、战力、身体结构、训练依据、武器或能力、伤势、场地、起始距离、方向、结尾胜负。普通人、武者、妖兽和能力者不能共用一套人体动作。允许在原有结果之间细化合理攻防；不加新武器、能力、伤势或重要破坏。

## 先编动作，再选机位

把每组攻防写为连续因果：

1. 起势：谁想打谁或摆脱谁；相距多远，支撑脚与身体朝向在哪里。
2. 诱导：眼神、佯攻、压迫路线或前一击迫使对方做何种防守。
3. 攻击：从身体哪侧起，沿什么高度和方向到达；重心如何送出。
4. 应对：格挡、封线、侧闪、撤步或贴身，哪个身体部位实际让开或接住攻击。
5. 接触：拳、掌、爪或兵器接触哪里；若落空，攻击惯性去向哪里。
6. 受力：头、躯干、持械手、衣料和脚步怎样按同一方向响应；不凭空腾飞。
7. 恢复：谁补步、回收手、重新站稳、维持或改变距离；由此暴露什么破绽。
8. 接招：下一动作必须来自前一结果，不能重起一招或切成对方已经倒地。

这套链条可跨镜头，也可由一镜完整承担。镜头连接要把上一镜的未完成拳线、落脚、持物手、伤势和双方方位原样接下。先画一条固定攻防轴，摄影机原则上保持同侧；跨轴时用可见绕位或中性全景重建。身体动作已快时，摄影机少动；跟移在判断和进攻阶段，关键格挡、接触与受力处停稳，随后再跟恢复与追击。

## 打击感与潇洒感

打击感来自危险距离缩短、蓄势与爆发的速度差、明确接触点、身体受力、短促动作声和一小段余波。音效放大可读的撞击，不能代替撞击。可在单一关键接触前短暂压慢判断或重心变化，命中即回常速；不连续抽帧。强调“潇洒”时，优先设计省力的避线、脚步抢位、借对方前冲改线与顺势收招，而非无因果旋转、空翻或环绕机位。

追逐需始终能回答谁在前、差几步、同往何方、前方有什么已建立的障碍、谁先发现出口、谁改变路线。远景/中景周期性重建空间，近景只承担判断或危机。人物不能切镜瞬移。

## 动作与特效同场

先把身体动作列成节点，再给节点挂特效：起手时出现、格挡时受压、反击时沿拳掌或兵器改线、命中时和人体受力及环境反馈同向、收招后衰减。特效遮住接触点、支撑脚、轮廓或胜负原因时，降低亮度、缩小范围或换机位。不得用满屏爆光跳过格挡与受力。

## 镜头级审计

逐镜口述“谁的哪只脚/手/爪从哪里到哪里”，再连读上一镜末句和下一镜首句。若无法连续表演，补必要的回收、换步或方向镜。术语必须与可见动作同句出现；“精彩套招、高速激战、连续格挡、猛击倒地”均不足以指导表演。

## 三层编排：招法因果、摄影路线、剪辑接点

第一层是演员可连续完成的动作线，先在不切镜的情况下口述或画出：谁从哪一侧迫近，哪只脚支撑，攻击线穿过哪里，防守将它带向哪侧，受力后谁补步。若在这一层说不通，增加机位和特效只会把缺口藏起来。第二层才是摄影路线：哪个阶段需要同框看清身体，哪个阶段贴近判断，哪个接触点应减弱相机运动。第三层是剪辑接点：在未完成动作上切、在声音上切、在眼神目标出现时切，或者留在同镜完成；每个切点明确上一镜最后姿态与下一镜第一姿态。

| 动作阶段 | 可用景别与运动 | 必须保护的信息 |
| --- | --- | --- |
| 逼近与试探 | 双人中全景、侧向跟移或稳定关系镜 | 原始距离、双方朝向、持物与逃跑路线 |
| 佯攻与判断 | 保留攻击手和被诱导的防守，必要时短跟或视线切换 | 第一击如何迫使对方抬臂/错步，下一招从哪里来 |
| 真正攻击与避让 | 同侧中景/全景；跟移动作方向，不先甩到结果 | 支撑脚、攻击高度、头肩怎样离线、攻击是接触还是落空 |
| 格挡/命中 | 接触处短暂停稳，必要的短近景仍保留双方身体参照 | 哪个部位碰到哪里、力量朝哪侧传、受击者如何承重 |
| 受力与恢复 | 允许短退跟或回到全景，观察补步和重新拉开距离 | 不能命中后直接切对手倒地；下一招的破绽来自恢复过程 |
| 追击或脱离 | 沿已建立方向跟拍、领先跟拍或稳定终点镜 | 胜负是否已定，谁追谁逃，持物和伤势状态 |

高动态摄影可与高动态动作配合，但两者不需同时达到峰值：人物加速时摄影机可以短跟，接触最复杂时摄影机稳定，受力后再接追拍。想加强速度感，优先调整运动起点与停止点、人物相对背景的位移、攻防距离和动作声，而不是把每镜改成甩镜。变速只强调一个关键判断、命中或重心失控：常速建立动作→短暂放缓使选择可见→恢复常速承受冲击→留下恢复或下一步，不能反复快慢交替。

镜头交接按镜头接力图复核：左/右脚支撑、左/右手持物、攻防手的位置、角色相对画面左右、运动方向、伤势、能力余光及环境受力。若镜头N结束时右拳仍前送，镜头N+1不能让右拳重新蓄势，也不能未经回收就突然用同手从另一方向格挡。若角色绕到对手背侧，必须在某个可见镜头完成绕位并重建攻击轴；不能靠切镜瞬移。表演重点是“为什么现在出这一招”：逃脱、保护道具、逼退、拖延或击败对手，目的不同，动作的终点不同。
