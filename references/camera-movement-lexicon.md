# 运镜词库：先知道“能做什么”，再决定“为何要做”

运动名称仅是工作词汇。正式镜头必须写摄影机起点、相对于谁运动、方向/幅度、触发、停止位置，以及运动前后观众多看懂什么。手持、稳定器、滑轨是运动质感或实现方式，不代替路径描述；“高动态运镜”更不是一个可执行的单独指令。除有充分动机的连续调度外，每镜只设一个主导运动，其他调整仅为保持主体清楚。

| 候选运动 | 可见执行与典型叙事任务 | 何时触发、停在哪里 | 何时不用或减弱 |
| --- | --- | --- | --- |
| 固定机位/锁定画框 | 摄影机不追人，让人物进出、靠近、退让改变画内权力；观众能自己判断关系 | 从完整可读的位置起，等人物行动或信息完成再切 | 不把“固定”写成无人行动的停滞镜头；空间尚未建立时勿锁死在碎片上 |
| 摇摄（Pan）/俯仰摇摄（Tilt） | 机身原地转向，追随视线、抬头发现高处信息，或在同一空间中连接声源和反应 | 已有视线、动作或声音触发；停在新主体及其反应可读的位置 | 不凭空扫景，不用摇摄替代缺失的空间交代；Tilt不是摄影机升降 |
| 缓推（Dolly in）/短促推进 | 摄影机实际靠近，让已发生的认知或决定获得更近的观看距离，同时背景透视改变 | 在人物收到刺激或决定显露时起；停在表演细节刚好可读的景别 | 台词和表演无变化时不例行推近；不把每句重话都拍成推镜 |
| 后撤/退跟（Dolly out） | 实际离开主体，可显露其被包围、失去控制、与他人拉开关系，也可给前行者让路 | 人物退让、真相使空间重新定义或威胁进入时起；停在新空间关系完整的位置 | 不把后撤自动等同于“悲伤”；没有新空间信息时保持原机位即可 |
| 横移/侧向跟移（Truck） | 摄影机与主体同侧并行，保持人物间距离、前后顺序和进退方向；也可让原有遮挡滑出，释放后景信息 | 人物并行、错步闪避、绕桌走位或遮挡解除时起；停在关系或接触点可读处 | 复杂攻击命中瞬间还持续横扫会遮掉受力；不为“层次感”无故穿过前景 |
| 领先跟拍/尾随跟拍 | 相机在行进前方或后方维持目标、追兵、出口的关系；领先可同时看见人物和背后威胁 | 路线、距离和目的地已经建立后跟随；在路线改变或危险被发现时结束/换位 | 只拍脸、完全看不到追兵或出口时，必须补空间镜；不能跟拍造成左右方向反转 |
| 短弧线绕移 | 绕人物一小段弧，改变谁遮挡谁、谁占前景，或在双方换位时重新建立权力关系 | 人物确实绕位、反转或被迫面向新目标时开始；停在新轴线与位置明确处 | 只是为了“360度震撼”不绕；格挡、命中线复杂时勿环绕掩盖攻防 |
| 大幅环绕/升降复合 | 仅当场面真的需要揭示新的空间规模、包围形态或多方位置，且模型容量容许 | 有明确空间揭示的起点和终点，运动过程中始终有可辨主体 | 一般短Part、多人快打或精密特效接触不优先；不能用一圈运动代替事件过程 |
| 摄影机升降（Pedestal/Crane/Jib） | 整个机位上升/下降，逐步展示层级、路线、压迫高度或新的空间事实 | 随人物登高/跌落、遮挡越过或局势扩展而动；停在新高度能读清的位置 | 不把机位升降写成“仰拍”；无已建立的高度关系时不要悬浮升起 |
| 手持贴随 | 小幅、不规则的摄影机身体反应贴住角色，传达受压、失衡、奔跑或受限认知 | 人物身体真的失稳或急迫时加重；判断、关键接触和落脚处减弱抖动 | “晃得厉害”不能代替攻击路径；文戏不因紧张就全程摇晃 |
| 短促甩镜（Whip pan） | 快速从已知声源、视线或攻击方向甩向具体目标；运动模糊只占交接过程 | 明确线索触发，甩到目标后立刻停稳，让观众看清结果 | 无目标或连续多次甩镜会丢失空间；不能用模糊跳过动作接触 |
| 镜头变焦（Zoom） | 机位不移动、焦距改变，主体尺度改变而空间透视不随摄影机移动；可表现远处目标被视觉隔离 | 人物锁定远处证据、误判或监视感有剧情依据时使用；在目标可读处停 | 不与实际推进混写；普通情绪靠近通常先考虑演员与机位距离 |
| 推拉变焦/希区柯克变焦 | 摄影机前后移动并反向变焦，使主体尺度相对稳定、背景空间伸缩，表达有根据的认知冲击 | 真相被人物接收的瞬间起，停在背景变化已表达新处境时 | 不是每次震惊都用；无场景纵深、人物反应或模型承载条件时不用 |
| 滚转/荷兰角变化 | 画面地平线有意倾斜或回正，强调认知、重力或世界规则的失衡 | 失衡事件发生后才倾，人物/局势恢复时归正或切回稳定轴 | 无触发的整场斜画面只是装饰；不能代替人物行为和空间结果 |
| 连续长镜头 | 摄影机可固定或分段移动，在不切的过程中让人物关系、信息和空间多次变化 | 预先规划各阶段演员走位、焦点/画框交接和结束点 | “一镜到底”本身不构成设计；对白与复杂动作超出Part容量时拆段 |

运镜的强度随观看任务变化，而不是一律越快越好：观众正在判断方位时稳定；人物开始行动时跟随；危险切近时适当缩短相机与身体的距离；唯一关键接触处稳住；受力后再允许相机随人物恢复或追击。真实的速度变化应有可见触发，不能每个镜头同时推拉、旋转、移焦、变速和全屏特效。
