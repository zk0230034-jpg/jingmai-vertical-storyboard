# 镜脉竖屏分镜导演 Skill

V10.0 面向国内及海外竖屏短剧的剧本诊断、导演方案、Seedance 分段、正式分镜及局部修订。入口是 `SKILL.md`；`references/` 提供原稿拍点覆盖、剧情节奏曲线、联合选镜、跨镜接力，以及运镜、景别、视角、构图、焦点、光声、动作和特效细则。`scripts/` 提供便携模板生成和分镜结构校验。

仓库只含通用方法，不含任何用户剧本或单集专用案例。示例不能当作待处理剧本。

## 使用

在支持从 GitHub 导入 Skill 的平台中，导入本仓库，确认其识别到根目录的 `SKILL.md`。随后提供剧本并说：

> 请使用「jingmai-vertical-storyboard」分析我提供的剧本。先核对集数、场次和剧情边界，提出导演方案；我确认后，再按指定模型、市场方向和集数生成连续分镜。原稿是唯一剧情事实源，不要把 Skill 示例写进剧情。

平台若只支持读取网页或附件、不能安装 Skill，请改用由 `scripts/build_portable_template.py` 生成的独立 Markdown 模板；仅发送 GitHub 地址不代表平台已经安装、读取或启用了全部参考文件。

## 验证

安装后先请目标 AI 复述 Skill 名称、它将按什么阶段读取哪些参考文件，再用一小段真实剧本测试。检查每个关键原稿拍点是否得到一次且仅一次的可见/可听呈现、导演方案是否影响逐镜、节奏是否有加速与停留、相邻镜头能否连演连剪，以及动作链、特效范围和原稿台词是否正确。结构校验脚本不能自动判断这些创作质量。
